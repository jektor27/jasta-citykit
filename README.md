# Jasta CityKit

**Статический каталог маленького города из открытых данных.**

CityKit превращает выгрузку магазинов в сайт: карточки, категории, FAQ, `schema.org`, `sitemap.xml` и уведомление поисковиков. Это не подборка случайных скриптов. Это один пайплайн, доведённый до живого результата.

## Почему такой продукт нужен

Маленькому городу не нужен тяжёлый движок и ручное копирование тысяч карточек. Нужна простая цепочка:

1. взять открытые данные;
2. привести их к одному виду;
3. убрать шум и дубли;
4. сгенерировать страницы;
5. проверить HTML;
6. обновить карту сайта и сообщить поисковикам.

CityKit делает именно это. Без базы данных, без CMS и без лишних зависимостей.

## Что внутри

- **Источники.** Адаптеры для локальных JSON-выгрузок 2GIS и OpenStreetMap, плюс демо-источник.
- **Сопоставление.** Нормализация `ё → е`, приведение улиц к одному виду, отсев банкоматов и парковок, поиск дублей по токенам.
- **Генерация.** Карточки магазинов, страницы категорий, главная, FAQ и JSON-LD `schema.org`.
- **Правило данных.** Если поля нет, CityKit не выдумывает его. В FAQ прямо просят уточнить по телефону.
- **Аудит.** Проверка `title`, `description`, `h1`, `lang`, `canonical`, `alt` и локальных ссылок. JSON-отчёт и ненулевой exit code для CI.
- **Публикация.** Генерация `sitemap.xml`, обновление `lastmod` и адаптер IndexNow. Ключ только из переменных окружения.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -e .
```

## Быстрый старт

```bash
python -m citykit collect --source demo --out data/raw.json
python -m citykit dedupe --in data/raw.json --out data/shops.json
python -m citykit build --in data/shops.json --out site/ --base-url https://example.org
python -m citykit faq --in data/shops.json --out data/faq.json
python -m citykit audit site/ --json report.json
python -m citykit notify --sitemap site/sitemap.xml --dry-run
```

Все команды, меняющие состояние, понимают `--dry-run`.

## Команды

| Команда | Что делает |
|---|---|
| `collect` | собирает магазины из демо, 2GIS или OSM в нормализованный JSON |
| `dedupe` | убирает шум и дубли по названию, адресу и телефону |
| `build` | строит статический сайт и `sitemap.xml` |
| `faq` | строит FAQ только из проверенных полей |
| `audit` | проверяет HTML и пишет JSON-отчёт |
| `notify` | отправляет URL в IndexNow; по умолчанию `dry-run` |

## Архитектура

```text
citykit/
  cli.py

tests/
examples/gusev-open-data/
```

## Правило честности

### Наша разработка

- пайплайн и порядок шагов;
- правила нормализации и сопоставления;
- генераторы карточек, категорий и FAQ;
- аудит HTML и целостности страниц;
- обновление `sitemap.xml` и публикация;
- тесты, README, пример и лицензия.

### Чужие сервисы

- данные 2GIS и OpenStreetMap;
- Bing, Яндекс и IndexNow;
- поисковики как получатели уведомлений.

Мы не выдаём чужое за своё. OpenStreetMap, 2GIS и поисковые системы остаются внешними источниками и получателями. Наш вклад — сборка, правила, генерация, аудит и публикация.

## Доказательство

Продукт не теоретический:

- живой каталог `gusev-flyer.ru`;
- 95 магазинов;
- 95 из 95 FAQ прошли проверку;
- покрытие 63,2%;
- базовые описания ПрофСтайла, Мегастроя и ЦентрСтрой выложены точечной правкой;
- `lastmod` обновлён, IndexNow отправлен, страницы отдаются с кэш-бастером.

## Что не попадает в репозиторий

- личные данные и непубличные формулировки;
- ключи, токены и приватные пути;
- коммерческие крючки;
- абсолютные пути разработчика;
- выдумки вроде «с 2005 года» или «бесплатная доставка от 2000 ₽».

Ключ IndexNow задаётся только через `CITYKIT_INDEXNOW_KEY`. Пример файла — `env.example`.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Покрыты нормализация, дедупликация, отсев шума, FAQ без выдумок и обновление `lastmod`.
